# api-docs

Актуальное описание API DTF. Официальная документация устарела: многие описанные в ней методы уже не работают. Это описание поддерживается и проверяется: каждая операция подтверждена записью трафика сайта, работающим клиентом [reDTF](https://github.com/re-dtf/client) или живым запросом и помечена датой проверки.

Сайт: https://re-dtf.github.io/api-docs/

## Что где

| Путь | Что |
| --- | --- |
| [docs/auth.md](docs/auth.md) | **Авторизация**: вход, обновление, токены, CORS и прокси, блокировки, открытые вопросы |
| [docs/conventions.md](docs/conventions.md) | версии в путях, формат ответов и ошибок, пагинация, медиа, как читать пометки |
| [docs/status.md](docs/status.md) | что проверено и что не описано |
| `openapi/*.yaml` | спецификация OpenAPI 3.1 по областям: `auth`, `feed`, `posts`, `comments`, `subsites`, `notifications`, `editor` |
| `openapi/shared/` | общие схемы, схемы авторизации и ответы; на них ссылаются остальные файлы |
| `SKILL.md` | вход для агентов: куда смотреть и как читать спецификацию |
| `site/index.html` | страница для людей на Scalar: список областей, поиск, пробные запросы к публичным методам. Бандлы и сводки рядом собирает `npm run build` |
| `scripts/` | `tasks.mjs` (lint, bundle через Redocly), `build-llms.mjs` (сводки для агентов) |

Каждая спецификация — отдельный полноценный OpenAPI-документ, общее подключено через `$ref`. Так агенту достаточно прочитать один файл нужной области, а не всё сразу.

## Правила

1. **Только подтверждённое.** У каждой операции есть `x-status`, `x-evidence` (`har`, `app`, `probe`) и `x-checked`. Не знаем — пишем «не проверено».
2. **Версия в пути обязательна.** Один путь на разных версиях отдаёт разные формы.
3. **Сырой HAR в репозиторий не добавлять.** В нём живые токены, куки и чужие данные. В спецификацию попадают только обезличенные примеры (вымышленные id, `0000…` вместо uuid).
4. **Источник правды — `openapi/`.** Проза в `docs/` дополняет, но не дублирует спецификацию.

## Проверка спецификации

Нужны Node.js и интернет (Redocly запускается через `npx`, версия зафиксирована в `scripts/tasks.mjs`, в проект ничего не ставится):

```bash
npm run lint     # проверка спецификаций
npm run build    # бандлы в site/bundle и llms.txt / llms-full.txt в site/
```
