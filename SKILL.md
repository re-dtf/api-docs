Этот каталог — проверенное описание API DTF. Описано только то, что подтверждено записями трафика сайта, работающим кодом reDTF и живыми запросами. Чего здесь нет, того в описании нет сознательно: не выдумывайте поля, параметры и эндпоинты, а если нужного нет, скажите об этом пользователю.

## Как читать спецификацию

- Версия в пути (`/v2.31/feed`) — часть эндпоинта. Один путь на другой версии отвечает иначе, это отдельная операция.
- У каждой операции есть `x-evidence` (`har`, `app`, `probe`) и `x-checked` (дата проверки). Фразы «не проверено» и «не снималось» в описаниях означают именно это.
- Запросы с телом — `multipart/form-data`, не JSON.
- Токен: `JWTAuthorization: Bearer <accessToken>`. Для `security: [{}, …]` токен необязателен, для `security: [{ JWTAuthorization: [] }]` обязателен.

## Правила

1. Токены, куки, почты и реальные id в файлы не записывать. Сырые HAR в репозиторий не добавлять.
2. Новое в спецификацию попадает только с доказательством: HAR, работающий вызов в клиенте или живой ответ. Укажите `x-evidence` и `x-checked`.
3. Правила репозитория: `AGENTS.md`.
